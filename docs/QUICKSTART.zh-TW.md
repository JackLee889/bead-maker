# 拼豆圖產生器

介面支援繁體中文、簡體中文、英語與日語。可在側欄頂部選擇語言，或開啟 `http://127.0.0.1:8501/?lang=zh-TW`。

1. Windows 請先安裝 Python 3.10 以上版本，解壓程式後執行 `start_windows.bat`，並保持命令視窗開啟。第一次安裝套件需要網路。
2. 上傳圖片，設定拼豆寬高，選擇通用色庫、品牌色卡、自動取色或匯入 CSV。
3. 點選「產生拼豆圖」，確認預覽與色號數量，再下載 PNG、CSV、Excel、PDF 或完整 ZIP。

每顆拼豆對應 Excel 中從 A1 開始的一個儲存格。品牌色號與匯入名稱保留原文。圖片處理與匯出均在執行程式的電腦上完成。

**自動語言：** 瀏覽器透過 Country.is 查詢 IP 地區。中國大陸使用簡體，台灣、香港、澳門使用繁體，日本使用日語，其他地區使用英語。查詢失敗時使用瀏覽器語言；圖片不會參與查詢。

**手動語言：** 手動選擇優先於 IP，會記住於目前瀏覽器並寫入網址的 `lang` 參數。切換語言保留圖片、設定、拼豆色彩與數量，匯出說明同步更新；選擇「Auto (IP) / 自动 / 自動」可恢復自動模式。

**離線使用：** 啟動前設定 `BEAD_MAKER_IP_LANGUAGE=0` 可停用 IP 查詢。翻譯與品牌色卡均隨程式提供。中文與日文 PDF 文字需要閱讀器支援對應的 CJK 字體。
