# ビーズ図案メーカー

日本語、英語、簡体字中国語、繁体字中国語に対応しています。サイドバー上部で言語を選ぶか、`http://127.0.0.1:8501/?lang=ja` を開いてください。

1. Windows では Python 3.10 以降をインストールし、展開したアプリの `start_windows.bat` を実行します。起動したコマンド画面は閉じないでください。初回のパッケージ導入にはネット接続が必要です。
2. 画像をアップロードしてビーズの縦横の数を指定し、汎用パレット、ブランドパレット、画像からの色抽出、CSV の読み込みから選びます。
3. 「ビーズ図案を作成」を押し、プレビューと数量を確認して、PNG、CSV、Excel、PDF または ZIP 一式をダウンロードします。

Excel では A1 から始まる各セルがビーズ 1 粒に対応します。ブランドの色番号や読み込んだ名前は原文のまま保持します。画像処理とファイル出力は、アプリを実行しているコンピューター内で行います。

**言語の自動選択：** ブラウザーから Country.is に IP の地域を問い合わせます。日本は日本語、中国本土は簡体字、台湾・香港・マカオは繁体字、その他は英語です。判定できない場合はブラウザーの言語に戻ります。画像は問い合わせに含めません。

**手動選択：** 手動で選んだ言語を IP 判定より優先し、このブラウザーと URL の `lang` パラメーターに保存します。切り替えても画像、設定、色と数量は変わらず、出力ファイルの説明文は更新されます。「Auto (IP) / 自动 / 自動」で自動モードに戻せます。

**オフライン利用：** 起動前に `BEAD_MAKER_IP_LANGUAGE=0` を設定すると IP 問い合わせを無効にできます。翻訳とブランドパレットはアプリに含まれます。中国語・日本語の PDF 表示には、対応する CJK フォントを扱える PDF リーダーが必要です。
