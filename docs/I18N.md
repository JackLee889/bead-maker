# 多语言与 IP 自动识别

适用版本：1.5.0。支持简体中文 `zh-CN`、繁体中文 `zh-TW`、英语 `en`、日语 `ja`。

## 使用与优先级

侧栏顶部提供固定可识别的“语言 / Language / 言語”入口。默认 `Auto (IP) / 自动 / 自動`。手动语言优先于 IP，不会被稍后返回的查询结果覆盖。

首次打开页面时，按以下顺序确定偏好：

1. 有效的 URL 参数 `lang=zh-CN`、`zh-TW`、`en`、`ja` 或 `auto`。
2. 当前浏览器之前保存的选择。
3. 自动模式。

自动模式按 IP 地区选择：

| 地区代码 | 语言 |
| --- | --- |
| CN | 简体中文 |
| TW、HK、MO | 繁体中文 |
| JP | 日语 |
| 其他有效地区 | 英语 |

IP 查询失败或被关闭时，使用浏览器语言。`zh-Hant`、`zh-TW`、`zh-HK`、`zh-MO` 回退繁体，其他 `zh` 回退简体，`ja` 回退日语，其他语言回退英语；无浏览器语言信息时回退简体。IP 只提供初始偏好，无法判断用户本人使用的语言；VPN、代理出口可能改变地区结果。

选择会保存在当前站点的 `localStorage`，并同步 `lang` 地址参数。换浏览器、域名或端口不共享偏好。浏览器禁止本地存储时，当前会话与地址参数仍可切换，下一次无参数访问可能重新识别。

## 网络请求与离线行为

浏览器请求固定 HTTPS 地址 `https://api.country.is/`，获取调用者 IP 所在地区。[Country.is 官方接口说明](https://country.is/) 定义了此查询行为。请求不带图片、色卡、Cookie 或页面来源，收到的完整 IP 不回传给 Python，也不写入应用缓存；组件只传递地区代码、偏好和浏览器语言。

单次查询超时为 1.8 秒。有效地区在当前浏览器缓存 24 小时，失败缓存 5 分钟，避免重复请求；同页运行中的查询共享一次请求，不随参数调整重复查询。自动识别尚未完成时先按浏览器语言显示，收到地区后更新。手动模式跳过新的 IP 查询，失败不会阻止本地图片处理和文件导出。

严格离线运行可以关闭 IP 查询。PowerShell：

```powershell
$env:BEAD_MAKER_IP_LANGUAGE = '0'
.venv\Scripts\python.exe -m streamlit run app.py
```

Windows 命令提示符可在执行 `start_windows.bat` 前运行 `set BEAD_MAKER_IP_LANGUAGE=0`；macOS/Linux 可使用 `BEAD_MAKER_IP_LANGUAGE=0 ./start_macos_linux.sh`。重启进程后生效。缺省启用，`0`、`false`、`off` 均表示关闭。

## 切换与导出

切换时保留上传图片、宽高、构图、图像设置、色卡、分组和索引矩阵。语言改变仅更新说明文字及导出，不重新调用图片缩放和颜色匹配。

- Excel 工作表名、表头和合计随语言变化；每颗拼豆仍对应从 A1 开始的一个单元格。
- PDF 标题、摘要、色表和分页说明随语言变化，使用阅读器支持的 Unicode CID 字体；不联网下载字体。
- 用量表和通用色名称随语言变化；真实品牌名、品牌色号和导入 CSV 中的名称作为数据保留原文。
- PNG 像素、所有色号、RGB、数量不变。CSV 表头、ZIP 文件名及设置键名保持固定，设置另存 `export_language`。
- 重新生成的 ZIP 包含与独立下载完全一致的 XLSX 字节。语言更新失败会清除旧下载，避免混用文件。

翻译覆盖应用自有界面；系统文件选择框及部分 Streamlit 原生工具按钮由浏览器、系统或框架提供。

## 开发维护

`locales/zh-CN.json`、`zh-TW.json`、`en.json`、`ja.json` 必须保持键集合一致，保留 `{name}`、`{count:,}` 等占位符。新增 UI 消息时更新四份文件，避免把变量先拼接进翻译键。不要将导入文本传给翻译器。

`language_ui.py` 管理偏好与稳定的控件值，`frontend/language.js` 管理浏览器查询和缓存；`localized_exports.py` 从同一个 `indices` 更新导出。未修改图片设置时保持生成指纹；导出语言单独记录。

运行项目的三组必需测试：

```powershell
.venv\Scripts\python.exe test_core.py
.venv\Scripts\python.exe -m unittest test_excel -v
.venv\Scripts\python.exe test_app.py
```

这些命令包括 `test_i18n.py` 中的语言映射、无效地区、占位符、导入文字保护和四语切换回归。浏览器验收还应检查首次识别、查询失败、手动优先、刷新记忆和窄屏布局；服务健康检查为 `/_stcore/health` 返回 `ok`。

装有 Node.js 的开发环境还可运行 `node --test test_language_frontend.mjs`，验证查询数据边界、缓存、超时、离线回退、存储不可用和迟到响应不会覆盖手动选择。Node.js 仅用于此项开发测试，运行应用不需要它。
