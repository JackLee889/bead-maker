# 拼豆图生成器

这是一个在浏览器里操作的 Python 程序。图片只在运行程序的电脑上处理，不会上传到外部服务器。

## 功能

- 简体中文、繁体中文、英语、日语界面；按访问者 IP 地区自动选择，也可手动切换并记住选择
- 上传 JPG、PNG、WEBP、BMP、TIFF、GIF，安装 `pillow-heif` 后支持 HEIC/HEIF
- 自定义横向/纵向拼豆数量、单颗尺寸（默认 2.6 mm）、裁剪方式、对比度和饱和度
- 内置 32 色、64 色通用屏幕参考色库
- 内置 MARD、COCO、漫漫、盼盼、咪小窝品牌色卡，可选版本和色号分组，离线使用
- 自动从原画提取 2–64 种颜色
- 导入带品牌和色号的 CSV，可从同一文件中选择指定品牌
- 采用 Lab 感知色差，而不是简单的 RGB 距离匹配
- 处理前后预览、带色号彩色网格、颜色用量统计
- 导出 PNG、UTF-8 CSV、Excel（XLSX）、A4 分页 PDF 和完整 ZIP 图纸包

修改设置或色库后，需要重新生成图纸；生成失败或更换、移除原画时，旧下载会清除。PDF 各分页使用一致的格子尺寸，页面会提前显示预计网格页数。

左侧参数按“尺寸与构图、图像与清晰度、色库与配色、图纸与打印”分组，可点击分组标题收起。每个参数下方直接显示用途、调整影响或注意事项，无需悬停查看；调整完成后点击侧栏顶部的“生成拼豆图”。下载区也标明了各格式的用途。

## 语言选择

侧栏顶部的“语言 / Language / 言語”支持 **简体中文、繁體中文、English、日本語**。默认选择 `Auto (IP) / 自动 / 自動`：中国大陆 IP 使用简体中文，台湾、香港、澳门 IP 使用繁体中文，日本 IP 使用日语，其他地区使用英语。

IP 查询由访问者浏览器向 [Country.is](https://country.is/) 发起，不使用服务器的出口 IP，也不传送图片。查询最多等待 1.8 秒；离线、超时或无法识别时按浏览器语言回退，非支持语言回退为英语，无浏览器语言信息时使用简体中文。VPN 或代理可能影响识别地区，可以随时手动切换。

手动选择优先于自动识别，会保存在当前浏览器并写入地址的 `lang` 参数，刷新后仍有效。切回自动选项即可重新使用地区规则。可直接使用 `?lang=zh-CN`、`?lang=zh-TW`、`?lang=en`、`?lang=ja` 或 `?lang=auto`；明确的链接参数优先于浏览器中保存的选择。

切换语言会保留上传图片、参数、品牌和已生成的像素映射；用量表、Excel 工作表与表头、PDF 标题及说明同步更新，无需重新转换图片。色号、RGB 和数量不变；品牌名及导入 CSV 中的名称保持原文。CSV 表头、ZIP 文件名和设置键名保持固定，`settings.json` 另记录 `export_language`。

翻译和色卡均随程序提供。希望完全禁止 IP 查询时，在启动前设置环境变量 `BEAD_MAKER_IP_LANGUAGE=0`；仍可手动切换或按浏览器语言显示。完整的优先级、缓存与维护说明见 [多语言说明](docs/I18N.md)。[English](docs/QUICKSTART.en.md) · [繁體中文](docs/QUICKSTART.zh-TW.md) · [日本語](docs/QUICKSTART.ja.md)

## 清晰度与细线保留

- 动漫、插画可使用“细线保留（动漫/插画）”，默认 0.65；配合“轻度锐化”默认 0.25，在缩小前后的处理过程中加强细暗线。照片或纹理较多时可把细线保留调为 0，避免纹理加重。
- 对比度默认 1.0；两项增强均设为 0 时使用原有缩放处理。增强无法保证保留小于一颗拼豆的所有细节，也不增加颗数。
- “对比预览缩放”默认适应窗口、完整显示，两侧预览框等高对齐。选择每颗像素大小可同时缩放两图，超出区域可横向、纵向滚动。此项不影响导出或要求重新生成。
- 彩色网格图按页面宽度完整显示，预览框内没有滚动条。点击图纸上方的“放大查看”或图纸本身，打开大图；用滚轮或加减按钮缩放，拖动查看四周细节，支持原始大小和适应窗口，按 Esc 或“关闭”返回。大图也没有滚动条，查看操作不改变生成结果或下载文件。“PNG 单格大小”影响图纸尺寸，不增加图案细节。
- 需要更多细节时，增大横向/纵向拼豆数；同时注意颗数和成品尺寸会增加。

自动取色支持纯色图片；自定义 CSV 支持 1–512 个颜色。ZIP 中的 `settings.json` 同时记录自动取色数量、PNG 单格尺寸、源文件名及校验值、色库校验值和应用版本，便于核对生成参数。

## 使用内置品牌色卡

在左侧“03 · 色库与配色”中，将“色库来源”切换为“内置品牌色卡”，选择拼豆品牌、色卡版本和参与配色的色号分组，再点击“生成拼豆图”。切换品牌后，程序会重新按该品牌的颜色匹配原画；图纸、用量统计及所有导出使用相同的品牌色号。

| 品牌 | 内置版本 | 可用颜色 |
| --- | --- | --- |
| MARD | 221 色基础版 / 291 色扩展版 | 221 / 291 |
| COCO | 291 色公开色卡 | 291 |
| 漫漫 | 278 色公开色卡 | 278 |
| 盼盼 | 289 条记录 | 285，已排除 4 条未确认色号 |
| 咪小窝 | 290 条记录 | 286，已排除 4 条未确认色号 |

默认使用所选版本的全部可用颜色。可取消自己没有的色号分组；至少保留一组才能生成。更改品牌、版本或分组后，旧结果和下载会清除，需重新生成。

色卡文件随程序保存在 `data/brand_palettes/`，使用时无需联网，也不新增依赖。公开整理的 RGB 是屏幕参考值，不代表品牌官方实测值；透明、夜光等材质效果需对照实物，单颗直径请按实际规格填写。使用自己的实测色表时，仍可选择导入 CSV。

数据日期为 2026-05-19，来源、固定版本及许可见 [色卡数据说明](data/brand_palettes/README.md)。品牌图纸 ZIP 内包含 `palette_source.txt`，并在 `settings.json` 记录品牌、版本、分组、来源和数据校验值。

## Excel 像素图导出

生成拼豆图后，进入“下载”，点击“下载像素单元格图（Excel）”。完整 ZIP 也包含 `bead_pattern.xlsx`。

- “拼豆图”工作表：转换后的一个像素对应一个真实单元格，左上角从 A1 开始。例如 40 × 25 颗对应 40 列、25 行，不是将 PNG 图片插入 Excel。
- 单元格使用匹配后的拼豆颜色填充，近似正方形，每 5 格加粗边界。字体或显示缩放不同可能产生轻微宽高差异。
- 生成时勾选“格子内显示色号”，Excel 内也会居中显示完整色号，长色号缩小显示；取消勾选则只保留色块。
- “色号统计”工作表保留品牌、色号、名称、HEX 和数量。数量是生成时的快照，手工修改图格后不会自动重新统计。
- 网格不包含 PNG 预览放大产生的额外像素、坐标装饰或外边距；最大为 300 × 300 个单元格。
- 如需清晰的分页制作图纸，优先使用现有 A4 PDF 导出。

升级已有安装后，请运行 `python -m pip install -r requirements.txt` 并重启程序；旧会话需要重新生成图纸。

## Windows 安装与运行

### 推荐：一键本地部署

1. 安装 Python 3.10 或更高版本，安装时勾选 **Add python.exe to PATH**。
2. 解压完整程序包；不要直接在 ZIP 压缩包预览窗口中运行。
3. 双击 `start_windows.bat`。
4. 第一次启动会创建 `.venv` 并下载依赖，完成后浏览器自动打开 `http://127.0.0.1:8501`。
5. 保持黑色命令窗口开启；关闭窗口即停止程序。以后仍双击同一个脚本启动。

`127.0.0.1` 只允许当前电脑访问。首次安装依赖需要联网；依赖安装完毕后，图片转换和文件导出不调用外部图片处理服务。

### Windows 手工部署

在本文件夹打开命令提示符：

```bat
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

程序会自动打开浏览器。以后再次使用时，只需进入本文件夹并运行：

```bat
.venv\Scripts\activate
python -m streamlit run app.py
```

也可以在终端运行 `./start_macos_linux.sh`。

如果浏览器没有自动打开，请手动访问 `http://127.0.0.1:8501`。如果提示端口被占用，请先关闭之前打开的拼豆图命令窗口，再重新运行。

## 下载源码并启动调试（Windows / VS Code）

1. 下载并完整解压源码包，使用 VS Code 打开解压后的 `bead_maker` 文件夹。
2. 安装 VS Code 的 Python 与 Python Debugger 扩展。
3. 先双击 `start_windows.bat` 一次，或在终端运行 `.venv\Scripts\python.exe -m pip install -r requirements-dev.txt`。
4. 在 VS Code 左侧打开“运行和调试”，选择 **Debug Bead Maker (F5)**，按 F5。
5. 可在 `app.py`、`core.py`、`excel_export.py` 中设置断点。浏览器地址为 `http://127.0.0.1:8501`；按 Shift+F5 停止。

另一种方式是双击 `debug_windows.bat`。它会启动网页并在 `127.0.0.1:5678` 等待调试器附加；随后在 VS Code 中选择 **Attach to debug_windows.bat** 并按 F5。调试脚本默认不暂停等待附加，因此即使暂时不连接调试器，网页也能正常启动。

常用断点位置：

- `app.py`：生成按钮后的图像处理和下载结果组装。
- `core.py`：`prepare_image()`、`map_to_palette()`、`make_pdf()`。
- `excel_export.py`：`make_xlsx()`，检查一像素一单元格的映射。

运行回归测试：

```bat
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe test_core.py
.venv\Scripts\python.exe -m unittest test_excel -v
.venv\Scripts\python.exe test_app.py
```

## 品牌色号表格式

点击网页中的“下载 CSV 色号表模板”，或参考 `sample_palette.csv`：

```csv
brand,code,name,hex
我的品牌,A01,白色,#FFFFFF
我的品牌,A02,黑色,#18191C
```

也可以不用 `hex`，改为 `r,g,b` 三列：

```csv
brand,code,name,r,g,b
我的品牌,A01,白色,255,255,255
我的品牌,A02,黑色,24,25,28
```

- `brand`/`品牌`：品牌名；一个 CSV 可以包含多个品牌
- `code`/`色号`：显示在拼豆格子里的编号
- `name`/`名称`：颜色名称
- `hex`：六位 RGB 屏幕色，例如 `#FF0000`

实体拼豆、显示器和照片的颜色会有差异。追求准确时，建议在固定光线下实拍自己的拼豆色卡并测量 RGB，再导入程序。

## 使用建议

- 人像从宽 60–100 颗开始，复杂画作从宽 100–160 颗开始。
- 实际制作通常不要开启过多颜色；24–40 色比较容易购买和整理。
- A4 打印默认 25 × 35 格一页，色号最清楚；需要省纸时可选择 40 × 55。
- 默认按 2.6 mm 拼豆估算，成品宽度约为“横向颗数 × 0.26 cm”；例如 100 × 100 颗约为 26 × 26 cm。使用其他规格时可手动修改单颗直径。
